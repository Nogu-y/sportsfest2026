# バレーボール

## 試合の進め方
1. 試合前にアップを行う
2. 各試合前にじゃんけんを行いサーブ権を決める
3. 試合を行う
4. 試合終了後、終了したコートから次試合のチームが練習を開始してもよい

## 競技ルール
- ルールは基本的に6人制バレーボールのルールに則り試合進行を行う
- 1チーム当たりの構成人数は6人+補欠2人とする
- 競技はトーナメント形式で行う
- 準々決勝までは1セットのみの10点先取で勝利とする
- 準々決勝まではルールにデュースを採用しないものとする
- 試合は1セット15点先取マッチで2セット先取で勝利とする
- 準々決勝までの試合は試合時間が10分を超えた時点でそれまでに獲得した得点でゲームの勝敗を決める
- 準決勝以降の試合は試合時間が20分が超えた時点でそれまでに獲得した得点でゲームの勝敗を決める
- ネットの高さは女子の規定である220cmに合わせる
- 6人制バレーボールのルールに則りローテーションやワンタッチのルールを適用する
- タッチネット、ドリブル等の判定は審判が行う
- 準決勝以降のイン・アウトの裁定は線審が行う
- 開始の合図が鳴ったらサーブ権を得たチームがサーブを相手コートに打ち、開始する


## 特記事項
- 競技開催中、参加者はすべて運営者の指示に従って行動すること
- 第二体育館の出入りにおいて東寮側の扉は使用しない
- 寮事務室側の扉は緊急時を除き使用しない
- 人数が足りないチームも試合に参加する事は可能とし、途中参加も可能とするが人数差による運営側の配慮等はないものとする
- 5分経過する前に出場選手が揃った場合にはその時点でアップを開始する
- 試合中に事故等アクシデントが起こった場合は実行委員と両チームキャプテンの相談の下、点数及び規定時間が満たされていない場合でも試合を強制終了し、その時点の得点数で勝敗を決めることとする


## 注意事項
- 会場内でのすべての暴力を禁じ、実行した者は処置の対象となる
- 体育大会実施時間内での一切の妨害行為を禁じ、実行した者は処置の対象となる
- 個人で所有しているボールの持ち込みを禁ずる
- チームの人数が足りない場合も5分経過時点でアップを開始する(予定時間の延長は認めない)
- 高専入学後に、バレーボール部に所属したことのある者・高体連主催大会もしくは高専大会に出場した経験のあるものは1人までとする
- アップ及び試合時間外のボールの使用を禁止する
- 反則行為に関しては審判が判定する。（特に悪質な反則行為に関しては厳格に判定する）
- 人数が足りないチームも試合に参加する事は可能とし、途中参加も可能とするが人数差による運営側の配慮等はないものとする
