# ソフトボール全完了 手入力テスト手順

生成日: 2026-05-20

対象API: `https://sportsfest-api.ichinoseki.ac.jp`

対象競技: ソフトボール `eventId=4`

目的:

- 人が実際のスタッフ画面から結果を入力する
- 勝ち上がり反映で次試合の参加者が埋まることを確認する
- 最後に得点計算を実行し、`scores` が期待通りになることを確認する

重要な注意:

- この手順は本番APIに結果を書き込みます。実行前にバックアップ状態を確認してください。
- `/api/public/live` は「現在のJST日付」の試合だけを返します。ソフトボールの予定日は `2026-05-21` と `2026-05-22` なので、2026-05-20 に入力した場合、反映確認は `/api/public/master` で行います。
- スタッフ画面で試合が `Waiting` のまま開始できない場合は、管理者またはスタッフ画面上部の「勝ち上がり反映」を実行して、参加者が確定した試合を `Preparing` にしてください。
- この表では全試合「左側の参加者を勝者」にしています。人手入力時は表の `入力` 欄どおりに入れてください。

基本操作:

1. スタッフ画面にログインする。
2. 自分の会場を選択する。
3. 対象試合で `開始` を押す。
4. `終了` を押す。
5. 表のスコアと勝者を入力し、`確定` を押す。
6. 次のラウンドの参加者が未確定なら、画面上部の `勝ち上がり反映` を押す。

## APIでの確認例

PowerShell:

```powershell
$master = Invoke-RestMethod -Uri https://sportsfest-api.ichinoseki.ac.jp/api/public/master
$softball = $master.events | Where-Object { $_.name -eq "ソフトボール" }
$softball
$master.scores | Where-Object { $_.eventId -eq 4 } | Sort-Object teamId, points
```

期待:

- `$softball.isCompleted` が `True`
- `eventId=4` の `scores` が 22行
- チーム別合計が上の表と一致する

チーム別合計確認:

```powershell
$teams = @{}
$master.teams | ForEach-Object { $teams[$_.id] = $_.name }
$master.scores |
  Where-Object { $_.eventId -eq 4 } |
  Group-Object teamId |
  ForEach-Object {
    [PSCustomObject]@{
      team = $teams[[int]$_.Name]
      total = ($_.Group | Measure-Object points -Sum).Sum
    }
  } |
  Sort-Object total -Descending
```
