# Next.js

Next.js 単体で見たい内容は、`page.tsx` や `layout.tsx`、`next.config.ts` のようなアプリ全体の土台です。  
ただしこのリポジトリでは `React` とセットで読む方が実務的なので、詳細は統合ページにまとめています。

- 統合ページ: [React / Next.js](./react-nextjs.md)

## Next.js だけ先に思い出すなら

- `page.tsx`: その URL の画面
- `layout.tsx`: 共通の枠
- `app router`: `src/app` ベースのルーティング
- `next.config.ts`: Next 全体の設定
- `transpilePackages`: workspace 内 package を変換対象に含める設定
