# PostgreSQL

## 何に使うか

データを保存するためのリレーショナルデータベースです。  
実務では「あとで検索・更新したいデータ」を安定して管理する基盤になります。

## このリポジトリでの役割

- API が使う保存先
- Docker Compose で開発用コンテナを起動する
- テーブル構造は Drizzle のスキーマ定義から管理する

## 最低限知っておくこと

- テーブル: データを入れる表
- カラム: 表の列
- レコード: 表の 1 行
- 主キー: 1 行を一意に識別する値

## キーワード

- `NOT NULL`: 値が必須
- `default`: 値未指定時の既定値
- `timestamp`: 日時
- `uuid`: 一意 ID
- `index`: 検索を速くする補助構造

## 実務で意識すること

- データ型を適切に選ぶ
- 必須項目かどうかを決める
- 後から変えにくい項目は慎重に決める
- 先にテーブル設計だけ確定させず、API の使い方と合わせて考える
- 「どう表示するか」より「どう保存・検索するか」で考える
